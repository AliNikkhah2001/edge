# Multi-Camera Synchronization & Global IDs

- **Temporal sync**: hardware trigger, master–slave, NTP, or pose-based (SynNet).
- **Global IDs**: Re-ID + spatio-temporal constraints (TransReID, LMGP, AGC/STC, MCTR).
